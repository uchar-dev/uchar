# typ:null joins WF-034 — the unspelled unknown-type sentinel is refused

Goal: the verifier refuses the explicit Onbekend unknown-type sentinel
(WF-034) but silently admits its unspelled twin: a value node whose typ is
plain null. The skip sits in spec/verifier/lib/checks.ml walk_expr
typ_checks (~1823-1830: None -> []) and in the WF-035 numeriek-operand arm
(~1896-1904: the catch-all skips None). A type:null literal then computes
as a bare unitless number in BOTH executors (ref eval.ml:353-357, clingo
translate.ml:1064-1068 — the None arm shares the Numeriek branch) — the
card-4 lens gap. Facts that make the fence safe: ZERO corpus files
(golden/rood/negatief) carry a type:null literal, and v0's resolver never
emits raw null (it always spells the Onbekend sentinel), so the fence
diverges from no v0 emission and breaks nothing.

The narrowest closing: fold typ:null into the EXISTING WF-034 refusal —
walk_expr's typ_checks rejects a value node without a static type citing
WF-034, exactly symmetric with the Onbekend arm, with the structurally
typeless legitimate node(s) (Lambda) special-cased by NODE KIND, not by
typ_of_expr result. Check after that change whether the WF-035 None-skip
is subsumed; narrow it in the same move ONLY if a type:null operand can
still reach it (smallest change wins). spec/IR-SPEC.md's WF-034 prose
widens by one sentence (the rule covers both the spelled sentinel and a
missing static type). The v0 SCHEMA stays untouched: Literal.type stays
nullable on the wire (mirror-then-diverge; the verifier is the fence).
Executor-level fences in ref/clingo are deliberately NOT added: the gates
replay only verifier-clean IR — record this rejection with its reason in
the card Result.

One new negatief case corpus/negatief/wf034-typeloos-literal/ (directory
name declares the rule): a schema-valid ir.json carrying a type:null
literal in an arithmetic position, which gate 3 must reject CITING WF-034.

Acceptance:
- Red-first: BEFORE the change, the new negatief ir.json passes the
  verifier (the gap demonstrated, output quoted); AFTER, it is rejected
  citing WF-034 and gate 3 is green including it.
- Every existing corpus file still verifies (zero type:null witnesses, so
  nothing may break); all twelve gates green in the worktree.
- Lambda (and any other structurally-typeless legitimate node) still
