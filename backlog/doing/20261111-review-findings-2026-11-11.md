# Review findings of 2026-11-11: fixes and norm decisions

Goal: the faults the reviews of 2026-11-11 reproduced in ref, clingo, Drools and the verifier are fixed, the
maintainer's norm decisions of that day about evaluation are carried out in spec and executors, and the by-catch of
card `review-candidates-triage` is fixed or struck. Each item lands as its own small commit with a witness that is red
before the fix; commit messages and Result lines say what the fault or the decision is, not a code from a review
report. Notes and probe documents beside the repository: `werk/review-fable/` (one folder per review); the decisions
in full: `werk/review-candidates-triage/normbesluiten.md`.

Reproduced faults:
- The verifier checks a sum type against its domain (WF-061) only where it is the datatype of an attribute or a
  parameter; a mismatch as a list element, a payload, a struct field or a function parameter passes, and ref and
  clingo then compute with a constructor the domain does not declare.
- The verifier's grid check of a timeline read per period (WF-126) does not see a value bound through a `Let`, which
  ref then faults on.
- The verifier's precision gate (WF-023) recognises a pro-rata write only in its bare form; bound through a `Let` it
  is refused while ref computes it.
- The EF-006 of an `ordered` allocation falls on the first share in sort order instead of case order (ch. 4.4).
- In the sum per period ref evaluates the `emptyFallback` before the members, so it reports EF-014 where ch. 5.11
  gives EF-037.
- The clip comparison in ref does not pass the static type (`static_numeric`/`static_date`), so text and date
  equality in a clip compute where ch. 1.2 gives false.
- ref stores the links of the case per role key, not per fact type: two fact types whose far role has one name share
  one key, and ref and clingo both count a berging as an aanmelding. The case-input side faults with EF-001 on a key
  the case does not write, and `creation_blocked` reads the same store.
- ref compares a StructLiteral positionally; fields written in another order than the declaration differ (ch. 11.2).
- A timeline write in ref keeps the computed unit instead of restating to the target's (ch. 3.4: 249 ct stays
  2,49 EUR where 2 is due).
- A sum per period under a rounding restates before it rounds (2 instead of 2,49; ch. 3.3, 3.5).
- A point read of an empty or absent timeline faults without a code where ch. 3.1 and 3.6 give leeg.
- The day-kind duration over two date-times tests precision on the run-time values instead of the static type, so
  the answer depends on which operand the case fills (ch. 3.8).
- ref evaluates a date comparison under the whole-period qualifier, which ch. 3.9 and 3.12 refuse by name.
- A point read of an unbound time-dependent parameter faults without EF-014.

Norm decisions of 2026-11-11:
- An allocation restates units: the maximum through the comparison (ch. 2.6), share and rest through the assignment
  gate (ch. 2.4), in ref, clingo and Drools; a golden as witness.
- A duplicate JSON key is a load error: one sentence in IR-SPEC; the shared OCaml loader and Drools (Jackson
  `STRICT_DUPLICATE_DETECTION`) refuse it; a test per reader.
- A label repeated in a role list of the case is one link, in the order of its first occurrence: one sentence in
  RUNTIME-SEMANTICS ch. 5.7a; ref changes.
- At session start (ch. 8.4) a vintage read without `asOfDate` is EF-011, one without a timeline in the parameter set
  EF-014; ch. 8.4 as an extra place in ch. 5.7b; two red cases.
- An empty dividend does not read the divisor (ch. 1.4 point 4): ref and clingo change; a golden as witness.
- WF-126 covers an initialisation version too: IR-SPEC, verifier, a negative case.
- The IfThenElse condition leaves WF-127's guard positions (WF-077 forbids every read there), with its verifier arm.
- A negative base with a fractional exponent is always a fault (ch. 2.2): ref and Drools change.
- The nested exception groups of an inherited base stay when a subtype replaces the base: they inherit as ordinary
  inherited exceptions above the own base; only the base's own consequence is replaced. One sentence in RS ch. 7.10;
  ref (`desugar.ml` `split_stack`), clingo and Drools change; a golden.
- The own total of an absent timeline in a session without an evaluation date faults: the date is tested before the
  absence. One sentence in RS ch. 3.6 and a red case; executors unchanged.

By-catch:
- clingo: a listed `maximum`/`minimum` inside a `Let` falls to the fallback CLINGO-008; translate it or refuse it with
  a code of its own.
- clingo: on three goldens with the recursion marker of a rule group removed (a document WF-045 refuses), clingo did
  not return within 5 minutes; a translation that cannot terminate refuses.
- Drools: `isPeriodArithmetic` does not count a `Construct` of a literal where ref's `is_period_arithmetic` does
  (measure first).
- frontend: four resolver gaps that now surface as RGS-394 (an undeclared attribute in a `Daarbij geldt` variable;
  an allocation without a unique relation after a subtype; a granularity key without a member; a version suffix on a
  form with one version), and a rule writing a whole dimensioned attribute without a frontend diagnostic (WF-125).
- The second half of `checks.ml` has 30 verifier arms without a negative case (list in
  `werk/review-fable/verifier-second-half/`): a negative per arm, and a proposal for gate 3 to hold "one negative per
  arm" by name.
- toolchain `Verbaliser`: `readRaw` turns a `ReflectiveOperationException` into null, a `Compound` with `GEEN` reads
  "A en niet B", `nlNumber` writes "-0,00"; hand to the toolchain session as text, not built here.
