# wf102-bronpad-start-niet-op-onderwerp

Violates **WF-102 (d)** (`spec/IR-SPEC.md` ch. 4.3), the FIRST join: the path
does not start at the fold subject.

    WF-102 FAIL /rules/resolvedRegels/0/waarde/bronPad/0: the opposite role
    'bergende boot' fills 'Boot', but this step starts at 'Jutter' (the fold
    subject) — a bronPad is a connected walk

The document drops the golden's first step and keeps the rest: Boot →
`geborgen vondsten` → `ingepakte kisten`, on a Jutter-subject rule. Every step
resolves, the steps join each other, and the path lands on the declared
element type — the ONLY defect is that its first step begins one type too far
out. This is the wire form of the very degradation the card exists to close
(the anchor that is not the subject), so it is the arm whose absence would
leave the field able to express the silent misbinding it was introduced to
replace. There is deliberately no bindingless fallback to soften it: WF-048
derives a relation from a type PAIR, and a path's intermediate types are its
own claim, not a consequence of its endpoints.
