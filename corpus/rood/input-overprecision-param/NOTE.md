# input-overprecision-param

The parameter branch of the input-precision fence: a case value whose
exact rational does not fit the PARAMETER's declared decimals (7.5 on
the 0-decimal vondstdrempel) MUST fault in both executors — the
reference interpreter's precision fence and the ASP backend's integer
scaling, same fragment. The document is the jutterswet-penningdrempel
golden verbatim; only the case is red.
