# uniqueness-two-temporal-keys

The single uniqueness form (no union) with TWO temporal key
components. The 2026-08-20 ever-uniqueness decision extends to the
single form compositionally (RS ch. 5.9 — the same shared tuple
function carries both forms), and so does its loud edge: with two
temporal components the tuple needs the same-moment join, which no
corpus case pins — both executors MUST refuse rather than cartesian-
pair values from different moments. The union twin is
`ever-unique-two-temporal-keys`; this red pins the SAME guard on the single
form's own code path.
